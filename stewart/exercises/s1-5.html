EXERCISE 1 극한·한쪽 극한·무한극한Limits,one-sided limits,and infinite limitsExercise 1 · p. 60 · PDF p. 97 개념 보기 · Concept
한국어

문제 요약

lim(x→2)f(x)=5의 의미를 설명하라. 동시에 f(2)=3일 수 있는가?

힌트. 점의 실제 함수값과 주변에서 접근하는 값을 구분한다.

해설.

  1. 2와 다른 입력을2에 충분히 가까이 고르면 함수값을 원하는 만큼5 가까이 만들 수 있다는 뜻이다.

  2. 극한은 x=2 자체의 값을 사용하지 않는다.

최종 답. 가능하다. 예:f(x)=5(x≠2),f(2)=3.

검산·주의점. 이 예에서 모든 뚫린 근방의 함수값은 정확히5이지만 지정점의 값은3이다.

English

Problem summary

Explain lim(x→2)f(x)=5.Can f(2)=3 nevertheless?

Hint. Distinguish the value at a point from values approached nearby.

Solution.

  1. Inputs distinct from2 can be chosen sufficiently close to2 so that their outputs are as close to5 as desired.

  2. The limit does not use the value at x=2 itself.

Final answer. Yes.For example f(x)=5 for x≠2 and f(2)=3.

Check and conditions. Every punctured neighborhood has output exactly5,while the assigned value at the point is3.

문제 요약

x→1⁻에서 f→3,x→1⁺에서 f→7이라는 말의 의미와 양쪽 극한 존재 여부를 설명하라.

힌트. 점의 실제 함수값과 주변에서 접근하는 값을 구분한다.

해설.

  1. 1보다 작은 입력으로 접근하면3,큰 입력으로 접근하면7에 가까워진다.

  2. 양쪽 극한이 존재하려면 두 한쪽 극한이 같은 값이어야 한다.

최종 답. 3≠7이므로 lim(x→1)f(x)는 존재하지 않는다.

검산·주의점. 서로 다른 두 접근 수열이 다른 출력 극한을 주므로 하나의 공통값을 정할 수 없다.

English

Problem summary

Explain what f→3 as x→1⁻ and f→7 as x→1⁺ mean,and whether the two-sided limit exists.

Hint. Distinguish the value at a point from values approached nearby.

Solution.

  1. Approaching with inputs below1 gives outputs near3;approaching from above gives outputs near7.

  2. A two-sided limit requires the one-sided limits to agree.

Final answer. Since3≠7,the two-sided limit does not exist.

Check and conditions. Two sequences approaching from opposite sides yield different output limits,excluding a common value.

문제 요약

(a)lim(x→−3)f(x)=∞,(b)lim(x→4⁺)f(x)=−∞의 의미를 설명하라.

힌트. 점의 실제 함수값과 주변에서 접근하는 값을 구분한다.

해설.

  1. (a)−3의 양쪽에서 충분히 가까운 입력을 택하면 함수값이 임의의 큰 양수보다 커진다.

  2. (b)4보다 큰 입력을4에 충분히 가깝게 택하면 함수값이 임의의 큰 음수보다 작아진다.

최종 답. 무한대는 실제 실수 함수값이 아니라 제한 없이 증가하거나 감소하는 행동을 뜻한다.

검산·주의점. 두 경우 모두 해당 접근 방향에서 수직점근선이 생기지만 f(−3),f(4)의 정의 여부는 별개이다.

English

Problem summary

Explain(a)lim(x→−3)f(x)=∞ and(b)lim(x→4⁺)f(x)=−∞.

Hint. Distinguish the value at a point from values approached nearby.

Solution.

  1. (a)For inputs sufficiently close to−3 from either side,outputs exceed any prescribed positive bound.

  2. (b)For inputs sufficiently close to4 from above,outputs fall below any prescribed negative bound.

Final answer. Infinity describes unbounded increase or decrease,not an ordinary real function value.

Check and conditions. Both imply vertical-asymptotic behavior in the indicated directions,but do not determine whether f(−3) or f(4) is defined.

문제 요약

그래프의 x=2에서 왼쪽 가지는 닫힌(2,3),오른쪽 가지는 열린(2,1)이고 x=4에서는 열린(4,4)로 양쪽이 이어진다.(a)2왼쪽,(b)2오른쪽,(c)2양쪽 극한,(d)f(2),(e)4양쪽 극한,(f)f(4)를 구하라.

힌트. 점의 실제 함수값과 주변에서 접근하는 값을 구분한다.

해설.

  1. 2에서는 두 접근 높이3과1이 다르다.4에서는 양쪽 높이는4이지만 그 점은 제외된다.

최종 답. (a)3,(b)1,(c)없음,(d)3,(e)4,(f)정의되지 않음.

검산·주의점. 닫힌 점은 함수값에만 적용하고 열린 점의 높이는 극한 판독에 사용했다.

English

Problem summary

At x=2 the graph has filled(2,3) on the left branch and open(2,1) on the right.At x=4 both sides approach open(4,4).Find(a)left limit at2,(b)right limit at2,(c)two-sided limit at2,(d)f(2),(e)limit at4,(f)f(4).

Hint. Distinguish the value at a point from values approached nearby.

Solution.

  1. At2,the approaching heights3 and1 differ.At4,both sides approach4,but the point itself is excluded.

Final answer. (a)3,(b)1,(c)does not exist,(d)3,(e)4,(f)undefined.

Check and conditions. Filled points determine function values;open-point heights can still determine limits.

English

Problem summary

The graph passes continuously through height2 at x=1.At x=3 it has left open point(3,1),right open point(3,4),and isolated filled point(3,3).Find(a)limit at1,(b)left limit at3,(c)right limit at3,(d)two-sided limit at3,(e)f(3).
