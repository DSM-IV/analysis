한국어

문제 요약

함수 \(f=- x^{2} - y^{2} + 16\), 기준점 \(\left( 2, \ 2\right)\). 접평면을 구하라.

힌트. 기준점의 함수값과 1계 편도함수를 구한다.

해설.

  1. 기준점 함수값은 \(8\); 두 편도함수는 \(f_x=- 2 x,f_y=- 2 y\).

  2. 기준점 기울기는 \(\left( -4, \ -4\right)\). \(L=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b)\)에 대입한다.

최종 답. \(z=- 4 x - 4 y + 24\).

검산·주의점. 선형식은 기준점의 함수값과 두 편도함수를 모두 보존한다.

English

Problem summary

For \(f=- x^{2} - y^{2} + 16\) at \(\left( 2, \ 2\right)\), Find the tangent plane.

Hint. Compute the value and first partial derivatives at the base point.

Solution.

  1. The base value is \(8\); the derivatives are \(f_x=- 2 x,f_y=- 2 y\).

  2. The gradient at the base point is \(\left( -4, \ -4\right)\). Substitute into \(L=f(a,b)+f_x(a,b)(x-a)+f_y(a,b)(y-b)\).

Final answer. \(z=- 4 x - 4 y + 24\).

Check and conditions. The linear formula matches the function value and both first partials at the base point.

Let \(f(x,y)=xy/(x^2+y^2)\) off the origin and f(0,0)=0. (a) Show both origin partials exist but f is not differentiable. (b) Explain discontinuity of the partial derivatives there.

Hint. Compute the value and first partial derivatives at the base point.

Solution.

  1. (a) Both axis traces are zero, so fx(0,0)=fy(0,0)=0. Along y=x≠0, however,f=1/2, so f is discontinuous and therefore not differentiable by exercise53.

  2. (b) \(f_x=y(y^2-x^2)/(x^2+y^2)^2\), \(f_y=x(x^2-y^2)/(x^2+y^2)^2\). Along x=0,fx=1/y; along y=0,fy=1/x, so both are unbounded near the origin.

Final answer. (a) Both partials are zero, but f is not differentiable. (b) Both partials are discontinuous.

Check and conditions. The value1/2 along y=x excludes the origin itself.
