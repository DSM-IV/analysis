한국어

문제 요약

f의 등고선은10 간격이다. 제약곡선 g=8은 위쪽에서 f=60 등고선에 접하고 아래쪽에서는 f=30 등고선에 접하는 모양이다. 제약상 최대·최소를 추정하라.

힌트. 목적함수의 기울기를 제약식 기울기의 선형결합으로 놓고 특이점과 경계도 검사한다.

해설.

  1. 제약곡선을 따라 움직일 때 만날 수 있는 등고선 값의 범위를 읽는다. 등고선과 제약곡선이 접하는 정칙점에서는 두 곡선의 법선이 평행하므로 \(\nabla f=\lambda\nabla g\)라는 대수적 조건으로 이어진다. 그림의 간격 때문에 답은 추정값이다.

  2. 제약곡선이 만나는 가장 큰 값과 가장 작은 값의 등고선을 찾는다.

  3. 극값에서는 보통 제약과 등고선이 접하므로 해당 접촉값을 읽는다.

최종 답. 최대 약60, 최소 약30.

검산·주의점. 원문 그림에서 값을 읽은 근삿값이다.

English

Problem summary

Contours of f differ by10. The constraint g=8 touches the f=60 contour above and the f=30 contour below. Estimate the constrained extrema.

Hint. Set the objective gradient equal to a linear combination of constraint gradients; also check singularities and boundaries.

Solution.

  1. Read the range of contour values reached while moving along the constraint. At regular tangencies their normals are parallel, giving \(\nabla f=\lambda\nabla g\). The contour spacing makes the graphical values estimates.

  2. Find the largest and smallest contour values reached by the constraint.

  3. At regular extrema the constraint and contour are tangent; read the contact values.

Final answer. Maximum approximately60; minimum approximately30.

Check and conditions. These are approximate values read from the source figure.

EXERCISE 2 라그랑주 승수Lagrange multipliersExercise 2 · p. 1064 · PDF p. 1101 개념 보기 · Concept
한국어

문제 요약

f=\(x^{2} + y\), \(x^{2} + y^{2} - 1\)=0. 라그랑주 승수로 최대·최소를 구하라. (a) 원과 여러 등위포물선을 그려 추정하고 (b) 정확한 값과 비교하라.

힌트. 목적함수의 기울기를 제약식 기울기의 선형결합으로 놓고 특이점과 경계도 검사한다.

해설.

  1. 목적함수를 \(f\), 등식 제약을 \(g=0\)으로 두면 정칙 극값에서 \(\nabla f=\lambda\nabla g\)이다. 이는 제약곡선·곡면에 접하는 방향으로 \(f\)가 일차적으로 변하지 않는다는 뜻이다. 좌표별 승수식과 원래 제약식을 함께 풀어야 한다.

  2. 승수 방정식: \(2 x \left(1 - \lambda\right)\)=0; \(- 2 \lambda y + 1\)=0, \(x^{2} + y^{2} - 1\)=0.

  3. 첫 승수식은 \(2x(1-\lambda)=0\)이다. x=0이면 원 위에서 y=±1. x≠0이면 λ=1이므로 두 번째 식 1=2λy에서 y=1/2, 제약에서 \(x=\pm\sqrt3/2\)이다. 이 네 점에서 목적값을 비교한다.

  4. 각 좌표가0인 경우를 따로 포함해 풀고 다음 후보값을 비교한다: \(\left( 0, \ -1\right)\): \(-1\); \(\left( 0, \ 1\right)\): \(1\); \(\left( \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\): \(\frac{5}{4}\); \(\left( - \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\): \(\frac{5}{4}\)

  5. (a) 자체 도해에서 접하는 포물선 값이 최소−1, 최대5/4로 보인다. (b) 위 승수계산과 일치한다.

  6. 승수 \(\lambda\)는 최댓값·최솟값 자체가 아니다. 가능한 좌표를 찾은 뒤 원래 \(f\)에 대입해 비교한다. 식을 좌표나 승수로 나눌 때 제외한 0의 경우와 \(\nabla g=0\)인 특이점은 별도로 확인한다.

최종 답. 최소 \(-1\) at \(\left( 0, \ -1\right)\); 최대 \(\frac{5}{4}\) at \(\left( \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\), \(\left( - \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\)

검산·주의점. 제약식과 후보값을 대입하고 극값 존재 조건을 확인했다.

English

Problem summary

f=\(x^{2} + y\), \(x^{2} + y^{2} - 1\)=0. Find maximum and minimum values by Lagrange multipliers. (a) Plot the circle and several level parabolas to estimate; (b) compare exact results.

Hint. Set the objective gradient equal to a linear combination of constraint gradients; also check singularities and boundaries.

Solution.

  1. Let \(f\) be the objective and \(g=0\) the constraint. At a regular constrained extremum, \(\nabla f=\lambda\nabla g\): the first-order change along tangent directions is zero. Solve the component equations together with the original constraint.

  2. Multiplier equations: \(2 x \left(1 - \lambda\right)\)=0; \(- 2 \lambda y + 1\)=0, \(x^{2} + y^{2} - 1\)=0.

  3. The first equation is \(2x(1-\lambda)=0\). If x=0, the circle gives y=±1. Otherwise λ=1, so 1=2λy gives y=1/2 and the constraint gives \(x=\pm\sqrt3/2\). Compare the objective at all four points.

  4. Include zero-coordinate cases separately and compare these candidate values: \(\left( 0, \ -1\right)\): \(-1\); \(\left( 0, \ 1\right)\): \(1\); \(\left( \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\): \(\frac{5}{4}\); \(\left( - \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\): \(\frac{5}{4}\)

  5. (a) The original plot shows tangent parabolas at values−1 and5/4. (b) The multiplier calculation agrees.

  6. The multiplier \(\lambda\) is not the extreme value. Evaluate the original \(f\) at the admissible coordinates and compare. Check zero cases excluded by division and singular constraint points where \(\nabla g=0\) separately.

Final answer. Minimum \(-1\) at \(\left( 0, \ -1\right)\); maximum \(\frac{5}{4}\) at \(\left( \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\), \(\left( - \frac{\sqrt{3}}{2}, \ \frac{1}{2}\right)\)

Check and conditions. Constraints, candidate values, and existence of extrema were checked.
