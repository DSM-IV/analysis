문제 요약

f의 그래프에 다음 변환을 가한 식을 구하라: (a)위로3, (b)아래로3, (c)오른쪽3, (d)왼쪽3, (e)x축 반사, (f)y축 반사, (g)세로3배 확대, (h)세로1/3배 축소.

힌트. 입력의 변화와 출력의 변화를 구분하고 합성은 안쪽부터 계산한다.

해설.

  1. 수평이동은 괄호 안 입력을 반대 부호로 바꾸며 수직이동·배율은 함수 밖에 적용한다.

최종 답. (a)\(y=f(x)+3\); (b)\(y=f(x)-3\); (c)\(y=f(x-3)\); (d)\(y=f(x+3)\); (e)\(y=-f(x)\); (f)\(y=f(-x)\); (g)\(y=3f(x)\); (h)\(y=\tfrac13f(x)\)

검산·주의점. 원래 점(a,b)는 오른쪽3 이동에서(a+3,b), 위로3 이동에서(a,b+3)으로 바뀌어 부호를 확인한다.

English

Problem summary

Find formulas after these transformations of f: (a)up3, (b)down3, (c)right3, (d)left3, (e)reflection across the x-axis, (f)reflection across the y-axis, (g)vertical stretch by3, (h)vertical scaling by1/3.

Hint. Distinguish input changes from output changes; evaluate composition from the inside out.

Solution.

  1. Horizontal shifts change the input with the opposite sign; vertical shifts and scales act outside the function.

Final answer. (a)\(y=f(x)+3\); (b)\(y=f(x)-3\); (c)\(y=f(x-3)\); (d)\(y=f(x+3)\); (e)\(y=-f(x)\); (f)\(y=f(-x)\); (g)\(y=3f(x)\); (h)\(y=\tfrac13f(x)\)

Check and conditions. An original point(a,b) becomes(a+3,b) under a right shift and(a,b+3) under an upward shift, checking the signs.

문제 요약

각 식의 그래프를 f에서 얻는 방법을 설명하라: (a)\(f(x)+8\), (b)\(f(x+8)\), (c)\(8f(x)\), (d)\(f(8x)\), (e)\(-f(x)-1\), (f)\(8f(\tfrac18x)\).

힌트. 입력의 변화와 출력의 변화를 구분하고 합성은 안쪽부터 계산한다.

해설.

  1. f(kx)는 기존 입력a가 새 x=a/k에 나타나므로 가로배율은1/|k|이다. 출력 앞 계수는 세로배율이다.

최종 답. (a)위로8; (b)왼쪽8; (c)세로8배; (d)가로길이1/8배; (e)x축 반사 후 아래로1; (f)가로·세로 모두8배

검산·주의점. 마지막 식에서(a,b)는(8a,8b)로 옮겨진다.

English

Problem summary

Describe how to obtain each graph from f: (a)\(f(x)+8\), (b)\(f(x+8)\), (c)\(8f(x)\), (d)\(f(8x)\), (e)\(-f(x)-1\), (f)\(8f(\tfrac18x)\).

Hint. Distinguish input changes from output changes; evaluate composition from the inside out.

Solution.

  1. For f(kx), an original input a appears at x=a/k, so the horizontal factor is1/|k|. A multiplier outside f sets the vertical factor.

Final answer. (a)up8; (b)left8; (c)vertical stretch by8; (d)horizontal scaling by1/8; (e)reflect across the x-axis, then shift down1; (f)stretch both horizontally and vertically by8

Check and conditions. For the final formula,(a,b) maps to(8a,8b).

힌트. 입력의 변화와 출력의 변화를 구분하고 합성은 안쪽부터 계산한다.

해설.

  1. 수평 위치는 괄호 안 이동으로, 높이와 부호는 함수 밖 연산으로 결정된다.

최종 답. (a)③,(b)①,(c)④,(d)⑤,(e)②.

검산·주의점. ③의 정의역은[4,7],②는[−6,−3],⑤는[−4,−1]이며 높이3,6,−3이 각각 맞는다.

English

Problem summary

The source branch f has domain[0,3] and maximum height3. Graph① is shifted up3,② left6 and scaled vertically by2,③ right4,④ scaled vertically by1/3,⑤ left4 and reflected across the x-axis. Match(a)f(x−4),(b)f(x)+3,(c)f(x)/3,(d)−f(x+4),(e)2f(x+6).

Hint. Distinguish input changes from output changes; evaluate composition from the inside out.

Solution.

  1. Input shifts determine horizontal position; outside operations determine height and sign.

Final answer. (a)③,(b)①,(c)④,(d)⑤,(e)②.

Check and conditions. The domains[4,7],[−6,−3],[−4,−1] for③,②,⑤ and the heights3,6,−3 verify the match.

문제 요약

f는 순서대로 점 [(-2, 2), (0, 0), (1, 3), (3, 2)]를 잇는 선분 그래프이다. (a)~(d) \(y=f(x)-3\), \(y=f(x+1)\), \(y=\tfrac12f(x)\), \(y=-f(x)\)를 그려라.

힌트. 입력의 변화와 출력의 변화를 구분하고 합성은 안쪽부터 계산한다.

해설.

  1. (a)아래3: 변환한 꼭짓점 [(-2, -1), (0, -3), (1, 0), (3, -1)].

  2. (b)왼쪽1: 변환한 꼭짓점 [(-3, 2), (-1, 0), (0, 3), (2, 2)].

  3. (c)세로1/2배: 변환한 꼭짓점 [(-2, 1.0), (0, 0.0), (1, 1.5), (3, 1.0)].

  4. (d)x축 반사: 변환한 꼭짓점 [(-2, -2), (0, 0), (1, -3), (3, -2)].

최종 답. 위 꼭짓점들을 원래 순서대로 연결한 첨부 네 그래프.

검산·주의점. 각 선분의 모든 점에 동일한 좌표 변환을 적용하므로 끝점과 중간 연결이 보존된다.

English

Problem summary

The graph f joins the points [(-2, 2), (0, 0), (1, 3), (3, 2)] with segments in order. Sketch(a)–(d) \(y=f(x)-3\), \(y=f(x+1)\), \(y=\tfrac12f(x)\), \(y=-f(x)\).

Hint. Distinguish input changes from output changes; evaluate composition from the inside out.

Solution.

  1. (a)down3: transformed vertices [(-2, -1), (0, -3), (1, 0), (3, -1)].

  2. (b)left1: transformed vertices [(-3, 2), (-1, 0), (0, 3), (2, 2)].

  3. (c)vertical factor1/2: transformed vertices [(-2, 1.0), (0, 0.0), (1, 1.5), (3, 1.0)].

  4. (d)x-axis reflection: transformed vertices [(-2, -2), (0, 0), (1, -3), (3, -2)].

Final answer. The four attached graphs join the transformed vertices in the original order.

Check and conditions. Applying the same coordinate transformation to every point preserves all segment connections and endpoints.
