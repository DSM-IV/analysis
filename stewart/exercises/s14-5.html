한국어

문제 요약

\(z=x y \left(x + y\right);\quad x=3 t,\quad y=t^{2}\). t에 대한 미분을 두 방법(연쇄법칙, 직접 대입)으로 구하라.

힌트. 각 의존 경로의 미분을 곱하고 모든 경로를 더한다.

해설.

  1. \(z_t=(3 t^{3} \left(t + 6\right)) + (t^{3} \left(12 t + 18\right))=t^{3} \left(15 t + 36\right)\).

  2. 직접 대입식은 \(z=3 t^{4} \left(t + 3\right)\). 이를 미분하면 같은 결과이다.

최종 답. \(z_{t}=t^{3} \left(15 t + 36\right)\).

검산·주의점. 합성함수를 먼저 대입한 뒤 기호 미분한 결과와 연쇄법칙 결과의 차이가0임을 검사했다. 식은 원래 함수와 모든 미분이 정의되는 영역에서 적용한다.

English

Problem summary

\(z=x y \left(x + y\right);\quad x=3 t,\quad y=t^{2}\). Find derivatives with respect to t by both chain rule and direct substitution.

Hint. Multiply derivatives along each dependency path, then sum all paths.

Solution.

  1. \(z_t=(3 t^{3} \left(t + 6\right)) + (t^{3} \left(12 t + 18\right))=t^{3} \left(15 t + 36\right)\).

  2. Direct substitution gives \(z=3 t^{4} \left(t + 3\right)\); differentiating yields the same result.

Final answer. \(z_{t}=t^{3} \left(15 t + 36\right)\).

Check and conditions. Symbolic differentiation after direct substitution agrees identically with the chain-rule result. Use the formulas where the original functions and derivatives are defined.

Problem summary
