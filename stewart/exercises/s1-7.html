EXERCISE 1 ε–δ 정의와 엄밀한 극한 증명Epsilon–delta definitions and rigorous limit proofsExercise 1 · p. 81 · PDF p. 118 개념 보기 · Concept
한국어

문제 요약

원본 그래프는 0.7\(\lt\)x\(\lt\)1.1에서 0.8\(\lt\)f(x)\(\lt\)1.2임을 보여 준다. |x−1|\(\lt\)δ이면 |f(x)−1|\(\lt\)0.2가 되는 δ를 구하라.

힌트. 출력 오차를 입력 거리로 제어하고, 선택한 δ가 모든 해당 입력에 적용됨을 보인다.

해설.

  1. 중심에서 두 입력 경계까지의 거리 중 작은 값을 고른다.

  2. \[\delta=\min\{1-0.7,1.1-1\}=0.1\]

최종 답. \[\delta=0.1\]

검산·주의점. 이 대칭 구간은 그래프가 허용한 입력 구간에 완전히 포함된다. 2번의 중심점 지정값은 뚫린 근방 조건으로 제외된다.

English

Problem summary

The source graph places f(x) between 0.8 and 1.2 when 0.7\(\lt\)x\(\lt\)1.1. Find δ ensuring |f(x)−1|\(\lt\)0.2 whenever |x−1|\(\lt\)δ.

Hint. Control output error by input distance and show that the chosen delta works for every eligible input.

Solution.

  1. Choose the smaller distance from the center to the two input boundaries.

  2. \[\delta=\min\{1-0.7,1.1-1\}=0.1\]

Final answer. \[\delta=0.1\]

Check and conditions. The symmetric interval lies entirely inside the graph’s permitted input interval. In problem 2 the assigned central value is excluded by the punctured-neighborhood condition.

문제 요약

그래프를 이용해 \(|x-4|<\delta\Longrightarrow|\sqrt x-2|<0.4\)를 보장하는 δ를 찾으라.

힌트. 출력 오차를 입력 거리로 제어하고, 선택한 δ가 모든 해당 입력에 적용됨을 보인다.

해설.

  1. 중심 a=4.0000000000를 포함한 허용 입력 구간 (x₋,x₊)은 (2.5600000000,5.7600000000)이다.

  2. 두 경계는 출력 1.6, 2.4를 함수식에 대입하여 역으로 구한다. 가까운 경계까지의 거리를 δ로 택한다.

검산·주의점. 표시한 소수는 정확한 경계 거리의 근삿값이다. 실제 사용할 때에는 그보다 조금 작은 값(예: 1.439)도 안전하다.

English

Problem summary

Use a graph to choose δ guaranteeing \(|x-4|<\delta\Longrightarrow|\sqrt x-2|<0.4\).

Hint. Control output error by input distance and show that the chosen delta works for every eligible input.

Solution.

  1. For center a=4.0000000000, the permitted interval (x₋,x₊) is (2.5600000000,5.7600000000).

  2. Find the boundaries by solving for outputs 1.6, 2.4, then choose the distance to the nearer boundary.

Final answer. \[\delta=\min\{a-x_-,x_+-a\}\approx1.4400000000\]

Check and conditions. The decimal approximates the exact boundary distance. A slightly smaller value, such as 1.439, is also safe.

문제 요약

극한 \(\lim_{x\to2}(x^3-3x+4)=6\)에서 ε=0.2,0.1에 대응하는 δ를 그래프로 구하라.

힌트. 출력 오차를 입력 거리로 제어하고, 선택한 δ가 모든 해당 입력에 적용됨을 보인다.

해설.

  1. ε=0.2: 출력 경계의 교점 x≈1.9774397435,2.0219012777; 가까운 거리≈0.0219012777이므로 δ=0.021901를 택한다.

  2. ε=0.1: 출력 경계의 교점 x≈1.9888055002,2.0110298569; 가까운 거리≈0.0110298569이므로 δ=0.011029를 택한다.

English

Problem summary

For \(\lim_{x\to2}(x^3-3x+4)=6\), use graphs to find δ for ε=0.2,0.1.

Hint. Control output error by input distance and show that the chosen delta works for every eligible input.

Solution.

  1. ε=0.2: the output boundaries intersect at x≈1.9774397435,2.0219012777. The nearer distance is ≈0.0219012777; choose δ=0.021901.

  2. ε=0.1: the output boundaries intersect at x≈1.9888055002,2.0110298569. The nearer distance is ≈0.0110298569; choose δ=0.011029.

Final answer. ε=0.2 → δ=0.021901; ε=0.1 → δ=0.011029

Check and conditions. Verified monotonicity on each chosen interval. The selected deltas are rounded downward from the limiting distances, preserving the strict output bounds.

해설.

  1. (a)ε=1로 얻은 근방에서 g>c−1이다. 임의 M>0에 f>max{1,M−c+1}인 근방과 교차시키면 f+g>M이다.

  2. (b)ε=c/2로 g>c/2>0을 보장한다. f>2M/c인 근방과 교차시키면 fg>M이다.

  3. (c)임의 N\(\lt\)0에 K=−N>0이라 하자. ε=−c/2로 g\(\lt\)c/2\(\lt\)0이고 f>2K/(−c)>0인 공통 근방을 택하면 fg\(\lt\)f·c/2\(\lt\)−K=N이다.

  4. 각 교차 근방은 두 양의 δ 중 작은 값을 사용하여 얻는다.

최종 답. (a)+∞; (b)c>0에서 +∞; (c)c\(\lt\)0에서 −∞.

검산·주의점. 곱의 증명에서는 f의 양수 조건을 함께 확보해 음수 g를 곱할 때 부등호 방향이 정확하게 유지되도록 했다.

English

Problem summary

Assume f(x)→∞ and g(x)→c∈ℝ as x→a. Prove from the definitions: (a)f+g→∞; (b)fg→∞ if c>0; (c)fg→−∞ if c\(\lt\)0.

Hint. Control output error by input distance and show that the chosen delta works for every eligible input.

Solution.

  1. (a)On a neighborhood obtained with ε=1, g>c−1. Intersect it with one where f>max{1,M−c+1} for an arbitrary M>0; then f+g>M.

  2. (b)Use ε=c/2 to ensure g>c/2>0. Intersect with a neighborhood where f>2M/c; then fg>M.

  3. (c)For any N\(\lt\)0 put K=−N>0. Use ε=−c/2 to obtain g\(\lt\)c/2\(\lt\)0 and choose a common neighborhood with f>2K/(−c)>0. Then fg\(\lt\)f·c/2\(\lt\)−K=N.

  4. Each common neighborhood is obtained by taking the smaller of the two positive deltas.

Final answer. (a)+∞; (b)+∞ when c>0; (c)−∞ when c\(\lt\)0.

Check and conditions. The product proofs also ensure f>0, so inequalities involving a negative g have the correct direction.
