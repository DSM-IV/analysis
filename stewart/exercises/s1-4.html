EXERCISE 1 할선·접선과 순간변화율Secants,tangents,and instantaneous ratesExercise 1 · p. 50 · PDF p. 87 개념 보기 · Concept
한국어

문제 요약

1000 gallon 탱크가30분에 비워진다. (t분,V gallon) 표=[(5, 694), (10, 444), (15, 250), (20, 111), (25, 28), (30, 0)]에서 P=(15,250).(a)t=5,10,20,25,30의 할선 기울기,(b)가까운 두 할선 평균으로 접선 기울기,(c)그래프에서15분 유출률을 추정하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. \[m_{PQ}=\frac{V(t)-250}{t-15}\]

  2. 5 → -44.4000; 10 → -38.8000; 20 → -27.8000; 25 → -22.2000; 30 → -16.6667

  3. 가장 가까운 양쪽 시각10,20의 기울기를 평균하면(−38.8−27.8)/2=−33.3 gallon/min이다.

최종 답. (a)−44.4,−38.8,−27.8,−22.2,−16.6667 gallon/min.(b,c)약−33.3 gallon/min; 물이 나가는 양의 속률은 약33.3 gallon/min.

검산·주의점. 음의 기울기는 남아 있는 물의 감소를 뜻한다. 그림의 매끄러운 보조곡선1000(1−t/30)²는 표를0.45 gallon 이내로 근사하며 실제 정확한 법칙으로 가정하지 않는다.

English

Problem summary

A1000-gallon tank empties in30 minutes. Using(t in min,V in gal)=[(5, 694), (10, 444), (15, 250), (20, 111), (25, 28), (30, 0)] and P=(15,250),find(a)secant slopes at t=5,10,20,25,30,(b)a tangent estimate by averaging two nearby secants,(c)a graphical flow-rate estimate at15 minutes.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. \[m_{PQ}=\frac{V(t)-250}{t-15}\]

  2. 5 → -44.4000; 10 → -38.8000; 20 → -27.8000; 25 → -22.2000; 30 → -16.6667

  3. Average the nearest slopes at10 and20:(−38.8−27.8)/2=−33.3 gal/min.

Final answer. (a)−44.4,−38.8,−27.8,−22.2,−16.6667 gal/min.(b,c)Approximately−33.3 gal/min;the positive outflow rate is about33.3 gal/min.

Check and conditions. The negative slope means remaining volume decreases. The smooth plotting guide1000(1−t/30)² approximates the table within0.45 gal and is not asserted as an exact law.

한국어

문제 요약

오후3시 후 t분의 누적 걸음수 표=[(0, 3438), (10, 4559), (20, 5622), (30, 6536), (40, 7398)]이다.(a)[0,40],[10,20],[20,30]의 할선 기울기와 의미,(b)3:20의 걸음/분을 두 기울기 평균으로 추정하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. (a)(7398−3438)/40=99,(5622−4559)/10=106.3,(6536−5622)/10=91.4이다. 이는 각 구간의 평균 걸음 속도이다.

  2. (b)t=20의 양쪽 평균은(106.3+91.4)/2=98.85이다.

최종 답. (a)99,106.3,91.4 걸음/분.(b)약98.85 걸음/분.

검산·주의점. 동일한20분 중앙 구간의 기울기(6536−4559)/20도98.85이다. 누적 걸음수 자체를 시간으로 나누지 않았다.

English

Problem summary

Cumulative steps at t minutes after3 PM are [(0, 3438), (10, 4559), (20, 5622), (30, 6536), (40, 7398)].(a)Find secant slopes on[0,40],[10,20],[20,30] and interpret them.(b)Estimate steps/min at3:20 by averaging nearby slopes.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. (a)(7398−3438)/40=99,(5622−4559)/10=106.3,(6536−5622)/10=91.4.These are average walking rates over the intervals.

  2. (b)The average of the two adjacent rates is(106.3+91.4)/2=98.85.

Final answer. (a)99,106.3,91.4 steps/min.(b)Approximately98.85 steps/min.

Check and conditions. The centered slope(6536−4559)/20 also gives98.85. The calculation uses changes in cumulative steps rather than the cumulative total divided by time.

EXERCISE 3 할선·접선과 순간변화율Secants,tangents,and instantaneous ratesExercise 3 · p. 50 · PDF p. 87 개념 보기 · Concept
한국어

문제 요약

P=(2,−1)은 y=1/(1−x) 위의 점이다.(a)x=1.5,1.9,1.99,1.999,2.5,2.1,2.01,2.001인 Q와의 할선 기울기를 소수6자리로,(b)접선 기울기 추정,(c)접선식을 구하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. \[m(x)=\frac{1/(1-x)+1}{x-2}=\frac1{x-1}\quad(x\ne1,2)\]

  2. 1.5 → 2.000000; 1.9 → 1.111111; 1.99 → 1.010101; 1.999 → 1.001001; 2.5 → 0.666667; 2.1 → 0.909091; 2.01 → 0.990099; 2.001 → 0.999001

  3. x가2로 양쪽에서 가까워지면 기울기는1로 다가간다. 점기울기식은 y+1=x−2이다.

최종 답. (a)1.5 → 2.000000; 1.9 → 1.111111; 1.99 → 1.010101; 1.999 → 1.001001; 2.5 → 0.666667; 2.1 → 0.909091; 2.01 → 0.990099; 2.001 → 0.999001;(b)1;(c)y=x−3.

검산·주의점. 원래 할선식과 단순화식의 차를 기호적으로0으로 확인했고 접선은(2,−1)을 지난다.

English

Problem summary

P=(2,−1) lies on y=1/(1−x).Find(a)secant slopes to Q at x=1.5,1.9,1.99,1.999,2.5,2.1,2.01,2.001 to6 decimals,(b)the estimated tangent slope,(c)the tangent equation.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. \[m(x)=\frac{1/(1-x)+1}{x-2}=\frac1{x-1}\quad(x\ne1,2)\]

  2. 1.5 → 2.000000; 1.9 → 1.111111; 1.99 → 1.010101; 1.999 → 1.001001; 2.5 → 0.666667; 2.1 → 0.909091; 2.01 → 0.990099; 2.001 → 0.999001

  3. As x approaches2 from either side,the slope approaches1. Point-slope form is y+1=x−2.

Final answer. (a)1.5 → 2.000000; 1.9 → 1.111111; 1.99 → 1.010101; 1.999 → 1.001001; 2.5 → 0.666667; 2.1 → 0.909091; 2.01 → 0.990099; 2.001 → 0.999001;(b)1;(c)y=x−3.

Check and conditions. The original and simplified secant expressions have symbolic difference zero;the tangent passes through(2,−1).

한국어

문제 요약

P=(0.5,0)은 y=cos(πx) 위의 점이다.(a)x=0,0.4,0.49,0.499,1,0.6,0.51,0.501에서 할선 기울기를6자리로,(b)접선 기울기,(c)접선식,(d)곡선·할선 둘·접선을 그려라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. \[m(x)=\frac{\cos(\pi x)}{x-1/2}\]

  2. 0 → -2.000000; 0.4 → -3.090170; 0.49 → -3.141076; 0.499 → -3.141587; 1 → -2.000000; 0.6 → -3.090170; 0.51 → -3.141076; 0.501 → -3.141587

  3. x=1/2+h로 쓰면 기울기는−sin(πh)/h이며 h→0에서−π로 다가간다.

최종 답. (a)0 → -2.000000; 0.4 → -3.090170; 0.49 → -3.141076; 0.499 → -3.141587; 1 → -2.000000; 0.6 → -3.090170; 0.51 → -3.141076; 0.501 → -3.141587;(b)−π≈−3.141593;(c)\(y=-\pi(x-1/2)\);(d)첨부 그래프.

검산·주의점. h와−h에서 같은 할선 기울기를 얻는다. 접선에 x=1/2를 넣으면0이며 독립 미분 검산도−π이다.

English

Problem summary

P=(0.5,0) lies on y=cos(πx).Find(a)secant slopes at x=0,0.4,0.49,0.499,1,0.6,0.51,0.501 to6 decimals,(b)tangent slope,(c)tangent equation,and(d)plot the curve,two secants,and tangent.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. \[m(x)=\frac{\cos(\pi x)}{x-1/2}\]

  2. 0 → -2.000000; 0.4 → -3.090170; 0.49 → -3.141076; 0.499 → -3.141587; 1 → -2.000000; 0.6 → -3.090170; 0.51 → -3.141076; 0.501 → -3.141587

  3. With x=1/2+h,the slope is−sin(πh)/h,which approaches−π as h→0.

Final answer. (a)0 → -2.000000; 0.4 → -3.090170; 0.49 → -3.141076; 0.499 → -3.141587; 1 → -2.000000; 0.6 → -3.090170; 0.51 → -3.141076; 0.501 → -3.141587;(b)−π≈−3.141593;(c)\(y=-\pi(x-1/2)\);(d)attached graph.

Check and conditions. The slopes agree for h and−h. The tangent gives0 at x=1/2;independent differentiation also gives−π.

EXERCISE 5 할선·접선과 순간변화율Secants,tangents,and instantaneous ratesExercise 5 · p. 50 · PDF p. 87 개념 보기 · Concept
한국어

문제 요약

강 수면에서275 ft 높은 다리에서 떨어지는 돌의 높이는 y=275−16t²이다.(a)t=4부터0.1,0.05,0.01초 구간 평균속도,(b)4초 순간속도를 추정하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. \[\frac{y(4+h)-y(4)}h=\frac{-128h-16h^2}h=-128-16h\]

  2. h가0으로 가면 상수항−128만 남는다.

최종 답. (a)−129.6,−128.8,−128.16 ft/s.(b)−128 ft/s,즉 아래로128 ft/s.

검산·주의점. 4.1초에도 y=6.04 ft>0이어서 세 구간은 모두 수면 충돌 전이다.

English

Problem summary

A stone dropped from a275-ft bridge has height y=275−16t² above the river.Find(a)average velocities starting at t=4 for durations0.1,0.05,0.01 s,and(b)instantaneous velocity at4 s.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. \[\frac{y(4+h)-y(4)}h=\frac{-128h-16h^2}h=-128-16h\]

  2. As h tends to zero,the limit is−128.

Final answer. (a)−129.6,−128.8,−128.16 ft/s.(b)−128 ft/s,or128 ft/s downward.

Check and conditions. At4.1 s the height is still6.04 ft>0,so all three intervals occur before impact.

문제 요약

화성에서 위로 던진 돌의 높이는 y=10t−1.86t²(m)이다.(a)[1,2],[1,1.5],[1,1.1],[1,1.01],[1,1.001]의 평균속도,(b)t=1 순간속도를 구하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. \[\frac{y(1+h)-y(1)}h=10-1.86(2+h)=6.28-1.86h\]

  2. 1 → 4.42000; 0.5 → 5.35000; 0.1 → 6.09400; 0.01 → 6.26140; 0.001 → 6.27814

최종 답. (a)4.42,5.35,6.094,6.2614,6.27814 m/s.(b)6.28 m/s.

검산·주의점. h를 줄이면 양의 평균속도가6.28로 증가하며 위로 이동 중이라는 부호와 맞는다.

English

Problem summary

On Mars a thrown rock has height y=10t−1.86t²(m).Find(a)average velocities on[1,2],[1,1.5],[1,1.1],[1,1.01],[1,1.001],and(b)instantaneous velocity at t=1.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. \[\frac{y(1+h)-y(1)}h=10-1.86(2+h)=6.28-1.86h\]

  2. 1 → 4.42000; 0.5 → 5.35000; 0.1 → 6.09400; 0.01 → 6.26140; 0.001 → 6.27814

Final answer. (a)4.42,5.35,6.094,6.2614,6.27814 m/s.(b)6.28 m/s.

Check and conditions. As h shrinks,the positive average velocity rises toward6.28,consistent with upward motion.

한국어

문제 요약

정지에서 출발한 오토바이의(t초,s ft) 표=[(0, 0), (1, 4.9), (2, 20.6), (3, 46.5), (4, 79.2), (5, 124.8), (6, 176.7)]이다.(a)[2,4],[3,4],[4,5],[4,6]의 평균속도,(b)그래프로 t=3 순간속도를 추정하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. (a)각 구간에서 위치차/시간차를 계산하면29.3,32.7,45.6,48.75이다.

  2. (b)t=3 양쪽의1초 기울기는25.9와32.7이다. 평균29.3을 접선 기울기로 택하면 약29~30 ft/s이다.

최종 답. (a)29.3,32.7,45.6,48.75 ft/s.(b)약29.3 ft/s(그래프에 따라 약30도 타당).

검산·주의점. 2~4초의 세 점을 지나는 이차 보간식은46.5+29.3(t−3)+3.4(t−3)²로 중앙 기울기29.3을 확인한다. 이산 자료만으로 정확한 순간속도를 확정하지 않는다.

English

Problem summary

A motorcycle accelerating from rest has(t seconds,s feet) data [(0, 0), (1, 4.9), (2, 20.6), (3, 46.5), (4, 79.2), (5, 124.8), (6, 176.7)].Find(a)average velocities on[2,4],[3,4],[4,5],[4,6],and(b)estimate instantaneous velocity at t=3 from a graph.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. (a)Position change divided by time change gives29.3,32.7,45.6,48.75.

  2. (b)The adjacent1-second slopes at t=3 are25.9 and32.7.Their average29.3 estimates the tangent slope,about29–30 ft/s.

Final answer. (a)29.3,32.7,45.6,48.75 ft/s.(b)Approximately29.3 ft/s(about30 is also a reasonable graph estimate).

Check and conditions. The local quadratic through t=2,3,4 is46.5+29.3(t−3)+3.4(t−3)²,confirming central slope29.3.Discrete data do not determine an exact instantaneous velocity.

EXERCISE 8 할선·접선과 순간변화율Secants,tangents,and instantaneous ratesExercise 8 · p. 50 · PDF p. 87 개념 보기 · Concept
한국어

문제 요약

위치 s(t)=2sin(πt)+3cos(πt)(cm),t초이다.(a)[1,2],[1,1.1],[1,1.01],[1,1.001]의 평균속도,(b)t=1의 순간속도를 추정하라.

힌트. 할선 기울기 Δy/Δx를 계산하고 기준점으로 다가갈 때의 값을 비교한다.

해설.

  1. s(1)=−3이고 t=1+h를 대입해 차분몫을 정리한다.

  2. \[\frac{s(1+h)-s(1)}h=\frac{-2\sin(\pi h)+3(1-\cos(\pi h))}h\]

  3. 1 → 6.000000; 0.1 → -4.712035; 0.01 → -6.134120; 0.001 → -6.268371

최종 답. (a)h=1,0.1,0.01,0.001 순서 6.000000, -4.712035, -6.134120, -6.268371 cm/s.(b)−2π≈−6.283185 cm/s.

검산·주의점. sin(πh)/h→π이고(1−cos(πh))/h→0이므로 극한은−2π이다. 긴 구간 평균이 양수여도 순간속도는 음수일 수 있다.

English

Problem summary

Position is s(t)=2sin(πt)+3cos(πt) cm at time t seconds.Find(a)average velocity on[1,2],[1,1.1],[1,1.01],[1,1.001],and(b)instantaneous velocity at1 second.

Hint. Compute the secant slope Δy/Δx and compare values as the second point approaches the base point.

Solution.

  1. Since s(1)=−3,substitute t=1+h and simplify the difference quotient.

  2. \[\frac{s(1+h)-s(1)}h=\frac{-2\sin(\pi h)+3(1-\cos(\pi h))}h\]

  3. 1 → 6.000000; 0.1 → -4.712035; 0.01 → -6.134120; 0.001 → -6.268371

Final answer. (a)For h=1,0.1,0.01,0.001: 6.000000, -4.712035, -6.134120, -6.268371 cm/s.(b)−2π≈−6.283185 cm/s.

Check and conditions. Since sin(πh)/h→π and(1−cos(πh))/h→0,the limit is−2π.A positive long-interval average does not force positive instantaneous velocity.
