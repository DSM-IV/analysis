한국어

문제 요약

Example 1의 \(B=[0,1]\times[-1,2]\times[0,3]\), \(f=xyz^2\)에 대해 \(y\), \(z\), \(x\) 순서로 적분하라.

힌트. 안쪽 변수의 적분에서는 나머지 변수를 상수로 두고, 사영 영역의 경계를 유지한다.

해설.

  1. \(y\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{-1}^{2}\left(x y z^{2}\right)\,dy=\frac{3 x z^{2}}{2}\]

  2. \(z\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{3}\left(\frac{3 x z^{2}}{2}\right)\,dz=\frac{27 x}{2}\]

  3. \(x\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{1}\left(\frac{27 x}{2}\right)\,dx=\frac{27}{4}\]

최종 답. \[I=\frac{27}{4}\]

검산·주의점. 각 단계의 원시함수를 미분하여 피적분함수를 복원하고 경계 대입을 기호 계산으로 확인했다.

English

Problem summary

For the box \(B=[0,1]\times[-1,2]\times[0,3]\) and \(f=xyz^2\) from Example 1, integrate in the order \(y\), then \(z\), then \(x\).

Hint. Hold the other variables fixed in the inner integral and preserve the projection bounds.

Solution.

  1. Integrate with respect to \(y\) and apply the limits. \[\int_{-1}^{2}\left(x y z^{2}\right)\,dy=\frac{3 x z^{2}}{2}\]

  2. Integrate with respect to \(z\) and apply the limits. \[\int_{0}^{3}\left(\frac{3 x z^{2}}{2}\right)\,dz=\frac{27 x}{2}\]

  3. Integrate with respect to \(x\) and apply the limits. \[\int_{0}^{1}\left(\frac{27 x}{2}\right)\,dx=\frac{27}{4}\]

Final answer. \[I=\frac{27}{4}\]

Check and conditions. Differentiating each available antiderivative recovers its integrand; symbolic endpoint evaluation checks every stage.

문제 요약

영역 \(E\): \(0\le x\le2,\ 0\le y\le1,\ 0\le z\le3\). \(\iiint_E x y + z^{2}\,dV\)를 계산하라. 서로 다른 세 적분 순서로 확인하라.

힌트. 안쪽 변수의 적분에서는 나머지 변수를 상수로 두고, 사영 영역의 경계를 유지한다.

해설.

  1. 경계의 대소관계를 확인하고 다음 순서로 쓴다. \[\int_{0}^{2}\int_{0}^{1}\int_{0}^{3}\left(x y + z^{2}\right)\,dz\,dy\,dx\]

  2. \(z\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{3}\left(x y + z^{2}\right)\,dz=3 x y + 9\]

  3. \(y\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{1}\left(3 x y + 9\right)\,dy=\frac{3 x}{2} + 9\]

  4. \(x\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{2}\left(\frac{3 x}{2} + 9\right)\,dx=21\]

  5. 다른 두 순서도 같은 직육면체를 나타낸다. \[\int_{0}^{1}\int_{0}^{3}\int_{0}^{2}\left(x y + z^{2}\right)\,dx\,dz\,dy=\int_{0}^{3}\int_{0}^{2}\int_{0}^{1}\left(x y + z^{2}\right)\,dy\,dx\,dz=21\]

최종 답. \[I=21\]

검산·주의점. 각 단계의 원시함수를 미분하여 피적분함수를 복원하고 경계 대입을 기호 계산으로 확인했다.

English

Problem summary

Region \(E\): \(0\le x\le2,\ 0\le y\le1,\ 0\le z\le3\). Evaluate \(\iiint_E x y + z^{2}\,dV\). Verify the value using three different orders.

Hint. Hold the other variables fixed in the inner integral and preserve the projection bounds.

Solution.

  1. The boundary inequalities give the following integration order. \[\int_{0}^{2}\int_{0}^{1}\int_{0}^{3}\left(x y + z^{2}\right)\,dz\,dy\,dx\]

  2. Integrate with respect to \(z\) and apply the limits. \[\int_{0}^{3}\left(x y + z^{2}\right)\,dz=3 x y + 9\]

  3. Integrate with respect to \(y\) and apply the limits. \[\int_{0}^{1}\left(3 x y + 9\right)\,dy=\frac{3 x}{2} + 9\]

  4. Integrate with respect to \(x\) and apply the limits. \[\int_{0}^{2}\left(\frac{3 x}{2} + 9\right)\,dx=21\]

  5. Two other orders describe the same box. \[\int_{0}^{1}\int_{0}^{3}\int_{0}^{2}\left(x y + z^{2}\right)\,dx\,dz\,dy=\int_{0}^{3}\int_{0}^{2}\int_{0}^{1}\left(x y + z^{2}\right)\,dy\,dx\,dz=21\]

Final answer. \[I=21\]

Check and conditions. Differentiating each available antiderivative recovers its integrand; symbolic endpoint evaluation checks every stage.

  2. \(y\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{\log{\left(x \right)}}\left(x e^{- y}\right)\,dy=x - 1\]

  3. \(x\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{0}^{2 z}\left(x - 1\right)\,dx=2 z \left(z - 1\right)\]

  4. \(z\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{1}^{2}\left(2 z \left(z - 1\right)\right)\,dz=\frac{5}{3}\]

Problem summary

Evaluate the iterated integral. \[\int_{1}^{2}\int_{0}^{2 z}\int_{0}^{\log{\left(x \right)}}\left(x e^{- y}\right)\,dy\,dx\,dz\]

Hint. Hold the other variables fixed in the inner integral and preserve the projection bounds.

Solution.

  1. Because \(\ln x\) is undefined at \(x=0\), first evaluate for \(x>0\) and interpret the endpoint as a limit. The resulting \(x-1\) extends continuously to zero.

  3. Integrate with respect to \(x\) and apply the limits. \[\int_{0}^{2 z}\left(x - 1\right)\,dx=2 z \left(z - 1\right)\]

  4. Integrate with respect to \(z\) and apply the limits. \[\int_{1}^{2}\left(2 z \left(z - 1\right)\right)\,dz=\frac{5}{3}\]

Final answer. \[I=\frac{5}{3}\]

힌트. 안쪽 변수의 적분에서는 나머지 변수를 상수로 두고, 사영 영역의 경계를 유지한다.

  2. \(z\)에 대해 적분하고 양 끝값을 대입한다. \[\int_{-1}^{2}\left(\frac{z \left(y + z\right)}{y}\right)\,dz=\frac{3}{2} + \frac{3}{y}\]

영역 \(x^2+y^2+z^2\le1,\ z\ge0\), 밀도 \(\rho=\sqrt{x^{2} + y^{2} + z^{2}}\)에 대해 (a) 질량, (b) 질량중심, (c) z축 관성모멘트의 적분식만 세워라.

힌트. 밀도를 포함한 적분 연산자를 정의하면 모든 양의 식을 간결하게 쓸 수 있다.

해설.

  1. 다음 연산자는 원래 영역과 밀도를 모두 포함한다. \[J[q]=\int_{-1}^{1}\int_{- \sqrt{1 - x^{2}}}^{\sqrt{1 - x^{2}}}\int_{0}^{\sqrt{- x^{2} - y^{2} + 1}}\left(\rho(x,y,z)\,q(x,y,z)\right)\,dz\,dy\,dx\]

  2. (a) 질량은 \(m=J[1]\)이다. (b) 좌표 모멘트는 \(J[x],J[y],J[z]\)이다.

  3. (c) z축의 거리제곱을 곱하므로 \(I_z=J[x^2+y^2]\)이다.

최종 답. \[m=J[1],\quad(\bar x,\bar y,\bar z)=\frac{(J[x],J[y],J[z])}{J[1]},\quad I_z=J[x^2+y^2]\]

검산·주의점. 경계를 대입하면 원래 곡면으로 돌아온다. 요청대로 적분값은 계산하지 않았다.

문제 요약

제1팔분공간의 \(x^2+y^2\le1,0\le z\le y\)에서 밀도 \(1+x+y+z\)의 (a) 질량, (b) 질량중심, (c) z축 관성모멘트를 정확히 구하라.

힌트. 질량은 밀도의 적분, 좌표 모멘트는 좌표×밀도의 적분이다.

해설.

  1. 원주좌표 \(x=r\cos\theta,y=r\sin\theta\)를 사용하고 부피요소의 \(r\)은 아래 밀도식에 이미 곱했다.

  2. 질량 적분을 계산한다. \[m=\int_{0}^{\frac{\pi}{2}}\int_{0}^{1}\int_{0}^{r \sin{\left(\theta \right)}}\left(r \left(r \sin{\left(\theta \right)} + r \cos{\left(\theta \right)} + z + 1\right)\right)\,dz\,dr\,d\theta=\frac{3 \pi}{32} + \frac{11}{24}\]

  3. 모멘트 적분을 계산한다. \[N_x=\int_{0}^{\frac{\pi}{2}}\int_{0}^{1}\int_{0}^{r \sin{\left(\theta \right)}}\left(r^{2} \left(r \sin{\left(\theta \right)} + r \cos{\left(\theta \right)} + z + 1\right) \cos{\left(\theta \right)}\right)\,dz\,dr\,d\theta=\frac{7}{24}\]

  4. 모멘트 적분을 계산한다. \[N_y=\int_{0}^{\frac{\pi}{2}}\int_{0}^{1}\int_{0}^{r \sin{\left(\theta \right)}}\left(r^{2} \left(r \sin{\left(\theta \right)} + r \cos{\left(\theta \right)} + z + 1\right) \sin{\left(\theta \right)}\right)\,dz\,dr\,d\theta=\frac{\pi}{16} + \frac{4}{15}\]

  5. 모멘트 적분을 계산한다. \[N_z=\int_{0}^{\frac{\pi}{2}}\int_{0}^{1}\int_{0}^{r \sin{\left(\theta \right)}}\left(r z \left(r \sin{\left(\theta \right)} + r \cos{\left(\theta \right)} + z + 1\right)\right)\,dz\,dr\,d\theta=\frac{\pi}{32} + \frac{13}{90}\]

  6. 모멘트 적분을 계산한다. \[I_z=\int_{0}^{\frac{\pi}{2}}\int_{0}^{1}\int_{0}^{r \sin{\left(\theta \right)}}\left(r \left(r^{2} \sin^{2}{\left(\theta \right)} + r^{2} \cos^{2}{\left(\theta \right)}\right) \left(r \sin{\left(\theta \right)} + r \cos{\left(\theta \right)} + z + 1\right)\right)\,dz\,dr\,d\theta=\frac{\pi}{16} + \frac{17}{60}\]

  7. \(\bar x=N_x/m,\bar y=N_y/m,\bar z=N_z/m\)으로 나눈다. \[m=\frac{3 \pi}{32} + \frac{11}{24},\qquad(\bar x,\bar y,\bar z)=\left( \frac{28}{9 \pi + 44}, \ \frac{2 \left(15 \pi + 64\right)}{5 \left(9 \pi + 44\right)}, \ \frac{45 \pi + 208}{15 \left(9 \pi + 44\right)}\right),\qquad I_z=\frac{\pi}{16} + \frac{17}{60}\]

최종 답. \[m=\frac{3 \pi}{32} + \frac{11}{24},\qquad(\bar x,\bar y,\bar z)=\left( \frac{28}{9 \pi + 44}, \ \frac{2 \left(15 \pi + 64\right)}{5 \left(9 \pi + 44\right)}, \ \frac{45 \pi + 208}{15 \left(9 \pi + 44\right)}\right),\qquad I_z=\frac{\pi}{16} + \frac{17}{60}\]

검산·주의점. 기호 적분으로 모든 모멘트를 계산했다. 질량은 양수이고, 질량중심이 입체의 좌표 범위 안에 있는지 확인했다. 대칭으로 0이 되는 좌표도 대조했다.

\([0,2]^3\)에서 \(f=Cxyz\), 바깥에서는 0이다. (a) C, (b) \(P(X\le1,Y\le1,Z\le1)\), (c) \(P(X+Y+Z\le1)\)을 구하라.

힌트. 전체 확률을 1로 정규화한 뒤 각 사건의 영역에서 적분한다.

해설.

  1. (a) \(1=C(\int_0^2x\,dx)^3=8C\)이므로 \(C=1/8\).

  2. (b) \(P=\frac18(\int_0^1x\,dx)^3=1/64\).

  3. (c) 사건은 제1팔분공간의 단위 사면체이다. \[P=\frac18\int_0^1\int_0^{1-x}\int_0^{1-x-y}xyz\,dz\,dy\,dx=\frac1{16}\int_0^1\int_0^{1-x}xy(1-x-y)^2dy\,dx\]

  4. y를 먼저 적분하면 \(\frac1{192}\int_0^1x(1-x)^4dx=1/5760\)이다.

최종 답. \[C=\frac18,\quad P_b=\frac1{64},\quad P_c=\frac1{5760}\]

Problem summary

Let \(f=Cxyz\) on \([0,2]^3\) and zero elsewhere. Find (a) C, (b) \(P(X\le1,Y\le1,Z\le1)\), (c) \(P(X+Y+Z\le1)\).

  1. (a) \(1=C(\int_0^2x\,dx)^3=8C\), hence \(C=1/8\).

  2. (b) \(P=\frac18(\int_0^1x\,dx)^3=1/64\).

  4. The y-integral gives \(\frac1{192}\int_0^1x(1-x)^4dx=1/5760\).

Final answer. \[C=\frac18,\quad P_b=\frac1{64},\quad P_c=\frac1{5760}\]
