## 분담과 검증

Astra 총괄이 스키마·범위·통합 및 §16.8–16.10 해설을 담당했다. Astra 해설 에이전트들이 §15.6–15.9, §16.1–16.5, §16.6–16.7을 분담했다. Terra가 정적 페이지 생성기를 구현했다. 최종 수학 검산과 통합 수정은 Astra가 수행했다.

- `exercise-content/manifest.json`: 예상 번호와 완료 번호를 명시한다. `check_site.py`가 요청 범위 591개 일치, 생성 페이지의 로컬 링크·앵커·ID, SVG XML, 기존 개념 페이지의 진입 링크를 검사한다.
- `build_exercises.py --check`: JSON 필수 항목, 출처, 한영 최종 수식, 문항 번호 및 생성 HTML 최신성을 검사한다. 번역 과정에서 수식 구분 위치가 달라질 수 있으므로 문제 본문의 수식 문자열 동일성은 자동 합격 기준으로 사용하지 않는다.
- `exercise-checks/`: 담당별 원본 대조 기록, SymPy 기호 적분·미분·행렬식, 독립 경계 적분, 고정밀 수치 적분 및 그림 생성 스크립트와 보고서.
- §15.6 적분 순서 변경은 영역 부등식의 표본 비교를 추가했다. §16.8은 독립적인 유향 경계 선적분 20건을 검산했다. §16.9는 직접 플럭스/발산 적분과 특이점 조건을 확인했다. Review 26(d)는 45자리·65자리 독립 수치 적분에서 1524.019017726569…를 얻었다.
- 생성 페이지와 수정된 기존 진입 페이지의 HTML 구조, 중복 ID, 임시 문구를 검사했다. 전체 599문항의 수식 구분자와 제어문자를 대조하여 §16.9 22번 최종답의 구분자 오류를 수정했다.
- §16.6–16.7은 113문항 구조 완결성과 39건 독립 계산 검산을 확인했다.
- Safari에서 목록, §15.6 33번의 긴 반복적분과 한국어 풀이 토글, §16.6 32번 뫼비우스 띠 그림을 시각 확인했다. 긴 인라인 수식에 가로 스크롤을 추가했다. **599문항 전부를 브라우저로 개별 검수한 것은 아니며, 별도의 모바일 기기 검수는 미실시다.**

## 주의해서 처리한 문항

- §15.8 21번: 그림과 부록 답을 재대조하여 하반구 껍질의 x≤0 절반으로 확정했다. 2≤ρ≤3, π/2≤φ≤π, π/2≤θ≤3π/2, 적분값 65π/4.
- §16.2 48번: 균일 상승 가정을 명시했다. 53번은 원문 격자에서 읽은 약 22 J의 추정값이다.
- §16.6 8·11·12번: 원본 대조로 매개화의 부호, sin(4v), 곡면 분류를 교정했다. 32번은 뫼비우스 띠의 비가향성을 설명한다.
- §16.7 8번: 원판 매개화가 원뿔을 두 번 덮는 점을 명시하고 기하학적 곡면 적분과 매개영역 전체 적분을 구분했다.
- §16.8 8번과 §16.9 14번: √z 항의 경계에서 C¹ 조건을 별도로 처리했다.
- §16.9 10번: 주어진 tan z가 경계면 내부에서 특이하므로 보통 의미의 플럭스는 존재하지 않는다. 형식적인 발산 적분 8/3을 실제 플럭스 답으로 제시하지 않는다.
- Chapter 16 Review 24(b): cot z, csc²z의 특이점 때문에 보통 의미의 선적분은 존재하지 않는다. 닫힌 경로라는 이유로 0을 적용하지 않는다.
- Chapter 16 Review 1번: 원호 방향을 원본 그림 및 부록과 대조하여 (a) 음수, (b) 양수로 확정했다.
