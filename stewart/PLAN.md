## 3. 페이지 구조

```
stewart/
  index.html          절 목록 28 (장별 그룹, 주차 배지, 예제 수, 진행 상태)
  s12-6.html … s16-10.html   절 페이지 28
  style.css           통합 CSS 복제 + .src-ref (la2와 동일)
  common.js
  GLOSSARY.md         calc2 용어집 상속 + Stewart 표기 규약 + 금칙어
  SOURCE-MAP.md       절→PDF 쪽, 환경 인벤토리(정의/정리/식/예제/그림), ERRATA
  GROUND-TRUTH.md     예제 145개 최종답 anchor(교재 답 + sympy 재계산)
  verify_structure.py 카드 수·마커·div 균형·LT-LETTER 검사 (stdlib)
  PLAN.md             이 문서
```

절 페이지 = 3블록:

1. **개념 해석** — `def-card`(정의), `thm-card`(정리·공식, 증명은 토글), `rem-card`(NOTE/WARNING 박스), `note-card`(절 도입·직관 설명 요약). 카드 id `c{절}-{순번}`(예 `c14-3-4`), 배지에 원문 번호 `src-ref`.
2. **예제 답안** — `exam-card`, id `ex{절}-{번호}`(예 `ex14-3-5`), 배지 `EXAMPLE 5`. ko/en 문제 재서술 + `풀이 보기 / Solution` 토글(자체 풀이, 교재와 다른 서술·필요 시 다른 방법 병기).
3. **연결** — calc2 대응 단원·카드 링크(`calc2/STEWART-DIFF.md` §2 매핑 사용), 공통과제 **번호만**(제출·참고 문항, 풀이 없음), 다음 절 링크.

이중언어: **ko = 해석(주 언어)**, **en = 재서술 요약**(정의·정리 진술은 수식 중심으로 정확히, 설명 산문은 요약). 원문 전재 대신 "원서 p.NNN 참조" 표기.

그림: 교재 그림 스캔 전재 금지. 필수 그림만 자체 SVG(이차곡면 6종, 수형도, Type I/II 화살표, 구면좌표 정의, 유향곡면·뫼비우스 띠, 스토크스 방향 규약, 발산정리 구멍 영역, 16.10 요약 도해).

## 6. 리스크와 대응

- **저작권**: 산문 전재·그림 스캔·PDF 커밋 금지, 예제 재서술, 자체 풀이. 검증 단계에서 "원문 문장과 유사도" 스팟체크(정의·정리 진술은 수학적 내용이라 허용, 설명 문단은 재서술 확인).

- **범위 팽창**: 연습문제·Problems Plus·Discovery Project는 2단계로 분리.
