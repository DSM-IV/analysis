## 핵심 금칙·주의
- linear combination / linearly independent = **일차결합 / 일차독립** ("선형결합·선형독립" 금지). linear transformation = **선형변환**, linear operator = **선형연산자**.
- eigenvalue / eigenvector = **고유값 / 고유벡터** (고윳값·특성값·아이겐값 금지). eigenspace = **고유공간**.
- characteristic polynomial = **특성다항식** (고유다항식 금지). splits = **분해된다** (첫 등장에 "(splits)" 병기 가능).
- diagonalizable / diagonalization = **대각화가능 / 대각화**. "대각화 가능" 띄어쓰기 금지 → 붙여 쓴다.
- rank / nullity = **계수(rank) / 퇴화차수(nullity)**. trace = **대각합**. determinant = **행렬식**.
- null space $N(T)$ / range $R(T)$ = **영공간 / 상** — 기호는 슬라이드의 $N(T)$, $R(T)$ 그대로 (LA1의 $\operatorname{Ker}$/$\operatorname{Im}$로 바꾸지 말 것).
- matrix representation $[T]_\beta$, $[T]_\beta^\gamma$ = **행렬표현**, coordinate vector $[v]_\beta$ = **좌표벡터**. 슬라이드의 $\mathcal{B}$(칼리그래피 B)는 `\mathcal{B}`로 전사, 풀이 PDF의 $\beta$는 `\beta`로 — 원문 그대로.
- similar = **닮은** (닮음), scalar matrix = **스칼라행렬**, identity matrix $I_n$ = **항등행렬**.
- inner product / inner product space = **내적 / 내적공간**, norm = **노름**, orthogonal / orthonormal = **직교 / 정규직교**, orthonormal basis = **정규직교기저**.
- Gram–Schmidt process = **그람-슈미트 과정**, orthogonal complement $W^\perp$ = **직교여공간**, orthogonal projection = **직교사영**.
- adjoint $T^*$ = **수반연산자** (수반), normal / self-adjoint = **정규 / 자기수반**, Hermitian = **에르미트**, unitary / orthogonal operator = **유니타리 / 직교 연산자**, spectral theorem = **스펙트럼 정리**, positive definite / semidefinite = **양의 정부호 / 양의 준정부호**.
- 사람 이름: 라이프니츠(Leibniz), 케일리(Cayley)-해밀턴(Hamilton), 그람(Gram)-슈미트(Schmidt), 프리드버그(Friedberg).
- 사이시옷: 최댓값/최솟값 (그러나 **고유값**은 관행대로 사이시옷 없이).

## 문체 규칙 (settheory·analysis2와 동일)
- 문제 서술: "-하라"체 ("증명하라", "구하라", "판정하라", "설명하라"). 진술·증명: "-이다"체.
- 증명/풀이 토글: 라벨("증명."/"Proof.") 없이 본문 바로 시작.
  - 하위 문항이 **전부** 증명형(prove/show) → "증명 보기/증명 접기 · Proof/Hide Proof" + `<div class="qed">□</div>`.
  - 판정(참/거짓)·계산·설명형이 하나라도 섞인 카드 → "풀이 보기/풀이 접기 · Solution/Hide Solution", qed 없음.
- 원문 증명(Theorem 5.2 등)은 en verbatim(■ 대신 사이트 규약 `<div class="qed">□</div>`) + ko 번역 미러.
- 수식·기호 원문 verbatim: $L_A$, $[T]_{\mathcal{B}}$, $\det(A - \lambda I_n)$, $\det(A - tI)$, $M_{n\times n}(\mathbb{F})$, $P_n(\mathbb{R})$, $\operatorname{tr}(A)$(슬라이드 표기 $tr(A)$는 `\operatorname{tr}(A)`로 정규화), $E_\lambda$.
- 슬라이드의 색 강조(파랑/빨강)·밑줄은 옮기지 않는다. 밑줄 라벨(Definition :, Theorem 1.3. : …)은 카드 제목·출처 라벨로 흡수한다.
- 슬라이드 원문 오타·문법 오류(예: "nonzer vector", "there exist an ordered basis", "the followings are true", "denoted by tr(M)", "Similary")는 en에 **그대로** 두고, ko는 바른 뜻으로 옮긴다.
