- **미분가능성의 정의 7** (PDF p.1052, 인쇄 1015): z = f(x,y)가 (a,b)에서 미분가능 ⇔
  Δz = f_x(a,b)Δx + f_y(a,b)Δy + ε₁Δx + ε₂Δy, (Δx,Δy)→(0,0)일 때 ε₁,ε₂→0.
  교안 calc2 전체를 검색해도 다변수 "미분가능성" 정의가 없음(`ch06`의 "미분가능한 함수"는 가정어로만 등장). **중요도 ★★**
- **정리 8** (p.1052): f_x, f_y가 (a,b) 근방에 존재하고 (a,b)에서 연속이면 f는 (a,b)에서 미분가능. (증명은 Appendix F.) **★★**
- **반례 f(x,y) = xy/(x²+y²), f(0,0)=0** (Figure 4, p.1052; 문제 53·54, p.1058): 편도함수는 존재하나 미분가능하지 않음 / 미분가능 ⇒ 연속. **★★**
- **전미분(total differential)의 정의** (식 10, p.1054): dz = f_x(x,y)dx + f_y(x,y)dy = (∂z/∂x)dx + (∂z/∂y)dy, 3변수는 dw = w_x dx + w_y dy + w_z dz (p.1056).
  교안은 dV = V_r dr + V_h dh(U07 yu05-1) 식으로 **쓰기만 하고 정의하지 않음**. 과제 14.4 #37이 "미분(differential)을 구하라" 유형이므로 직결. **★★★**
- **Δz와 dz의 비교** (Example 4, p.1054–1055; 문제 39·40): 실제 증분 Δz = f(2.05,2.96) − f(2,3) = 0.6449 vs dz = 0.65. 교안에 대응 카드 전무. 과제 14.4 #40이 정확히 이 유형. **★★★**
- **표(수치자료)로부터의 선형근사** (Example 3 heat index, p.1053; 문제 28·29·30): 격자 표에서 f_T, f_H를 추정해 L을 세움. 교안 yu03은 **공식**이 주어진 체감온도라 유형이 다름. **★★**

## 6. 사이트 반영 권고

1. **U07에 2계 방향도함수 D²ᵤf = f_xx a² + 2f_xy ab + f_yy b² 카드를 신설**(과제 14.6 #45 직결, 현재 개념 자체가 없음).
2. **U07에 전미분 dz = f_x dx + f_y dy를 정의로 명시하고 "Δz vs dz 비교" 카드를 추가**(과제 14.4 #37·#40 직결), 미분가능성 정의 7·정리 8도 개념 박스로 보강.
3. **U08에 경계가 곡선인 절대극값 카드 2종 추가**: 원판 x²+y² ≤ 1 위의 절대 최대·최소(14.7 #39)와 부등식 영역에서 내부 임계점 + 경계 라그랑주를 결합하는 절차(14.8 #27, Stewart Example 4).
4. 표기 정비: 법선을 **대칭방정식**으로도 병기, 접평면을 z = f(x,y)형 식 2로도 제시, 라그랑주는 ex02(1)의 g/h 문자 충돌을 f/g로 통일.
5. 오차 상계(½M(Σ|Δ|)², (1/6)M(Σ|Δ|)³)와 3차근사식은 Stewart에 없으므로 **"교재 외 심화"로 라벨링**하고, 대신 표에서 읽는 선형근사(14.4 Ex 3·문제 28–30)와 각 θ 방향도함수(식 6, 문제 4–7) 카드를 보충.
