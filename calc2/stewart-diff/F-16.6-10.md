## 4. 표기·용어·정의 방식 차이

교안 카드의 실제 표기를 세어 확인: **`ch13.html`에 `d\sigma` 74회 / `dS` 4회, `ch14.html`에 `d\sigma` 48회 / `dS` 0회.** `dS` 4회는 전부 임용 기출 문항 U13 pr03(`\iint_G \cos^2\frac{\theta}{2}\,dS`, `dS=\sec\theta\,dA`)에서만 나온다. 즉 교안 본체는 **일관되게 Thomas의 dσ**를 쓴다.

| 항목 | 교안(Thomas 기반) 실제 표기 | Stewart 9판 |
|---|---|---|
| 면적소 | `d\sigma` — U13 ex02: "$d\sigma=\|\mathbf{r}_x\times\mathbf{r}_y\|\,dx\,dy$", U13 ex03: "$d\sigma=r\sqrt2\,dr\,d\theta$" | `dS` — "∬_S f dS = ∬_D f(r(u,v))\|r_u×r_v\| dA" (식 2) |
| 스칼라 면적분 | U13 ex03: `\iint_S G\,d\sigma`, U13 yu03-3: `\iint_S \sqrt{x(1+2z)}\,d\sigma` | `∬_S f(x,y,z) dS` |
| 플럭스 | U13 ex04: `\iint_S\mathbf{F}\cdot\mathbf{n}\,d\sigma`, 중간식 `\mathbf{n}\,d\sigma=(2x,-1,0)\,dx\,dz` | `∬_S F·dS = ∬_S F·n dS` (정의 8) — **벡터 면적소 dS를 별도 정의** |
| 플럭스 계산식 | 교안은 n dσ = (r_u×r_v) du dv 를 계산 과정에서 암묵적으로 사용, 공식으로 진술하지 않음 | 식 9: `∬_S F·dS = ∬_D F·(r_u×r_v) dA` 를 번호 붙은 공식으로 제시 |
| 유출 vs 플럭스 | 한국어 용어 **"유출"** 사용 (ch13 14회, ch14 25회). "플럭스" 0회 | flux (=surface integral of F over S) |
| 스토크스 정리 | U14 ex02: `\oint_C\mathbf{F}\cdot d\mathbf{r}=\iint_S(\nabla\times\mathbf{F})\cdot\mathbf{n}\,d\sigma` | `∫_C F·dr = ∬_S curl F·dS` |
| 발산정리 | U14 ex04: `\iint_S\mathbf{F}\cdot\mathbf{n}\,d\sigma=\iiint_D\nabla\cdot\mathbf{F}\,dV` (영역 문자 **D**) | `∬_S F·dS = ∭_E div F dV` (영역 문자 **E**) |
| 회전·발산 연산자 | `\nabla\times\mathbf{F}`, `\nabla\cdot\mathbf{F}` (U14 ex01·ex03 제목도 "벡터장의 회전/발산") | `curl F`, `div F` (∇ 표기는 보조적으로만 병기) |
| 매개곡면 | `\mathbf{r}(r,\theta)`, `\mathbf{r}(x,y)`, `\mathbf{r}(u,\theta)` 등 매개변수 이름을 문제마다 달리 씀 (U13 ex01·yu01-4, U14 pr03) | 일관되게 `r(u,v)`, 접벡터는 `r_u`, `r_v` |
| 향(orientation) | "**향**"으로 번역. "$\mathbf{n}\cdot\mathbf{i}\geq0$이 되도록 $S$의 향 $\mathbf{n}$을 정할 때"(U13 ex04), "$z$축으로부터 멀어지도록"(yu04-2), "위에서 바라봤을 때 시계 반대 방향"(U14 yu02-2~4). "유향곡면"은 ch13 meta keywords와 ch14 pr12 단서에만 등장 | oriented surface / orientable / positive orientation(닫힌곡면=바깥) / upward·downward orientation을 **정의로 도입** |
| 라플라시안 | U14 pr09·pr11: `\nabla^2 f`, "조화함수(harmonic function)" | `∇²f`, Review 23에서 harmonic function |
| 곡면 넓이 | U13 ex02: 매개형·**음함수형**·양함수형 3종 | 매개형(정의 6)·그래프형(식 9) 2종 |

## 6. 사이트 반영 권고

1. **표기 전면 교체 최우선**: U13·U14의 `d\sigma` 122곳을 `dS`로, `\iint_S F·n dσ`를 `\iint_S \mathbf{F}\cdot d\mathbf{S}`로, `∇×F`/`∇·F`를 `curl F`/`div F` 병기로 바꾸고, 발산정리 영역 문자 D→E로 통일한다.
