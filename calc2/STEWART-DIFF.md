## 1. 한눈에 보는 결론

1. **범위는 대체로 겹치나 구조가 1:1이 아니다.** 교안 U05–U14(10단원)가 Stewart 14–16장(27개 절)을 덮는다. 단 (a) U01–U04는 강의 범위 밖, (b) 곡면 넓이(15.5)는 U09가 아니라 U13에, (c) 3차원 curl·div(16.5)는 U12가 아니라 U14에, (d) 변수변환(15.9)은 U09/U10에 섞여 있다.
2. **"응용" 절이 세 군데 통째로 비어 있다.** 밀도·질량·질량중심·관성모멘트가 이중적분(15.4), 삼중적분(15.6–15.8), 선적분·면적분(16.2, 16.7) 어디에도 없다. 공통과제 제출 문항 중 15.4 #7·#12·#18, 15.6 #44, 15.7 #27(b), 15.8 #31(b), 16.2 #36, 16.7 #39가 여기서 나온다.
3. **교안은 순수 문제집이라 정의·정리 카드가 없다.** ε-δ 극한 정의, Clairaut, 미분가능성 정의(14.4 Def 7)·정리 8, 연쇄법칙 정리와 수형도, Fubini, Type I/II·type 1/2/3 영역, 경로 독립 동치 정리(16.3 Thm 3·4), 유향곡면·뫼비우스 띠, 스토크스 경계 방향 규약, 발산정리 구멍 확장, 16.10 요약표가 모두 없다.
4. **표기 충돌이 가장 큰 곳은 16장이다.** 벡터장 성분 `M i + N j + P k`(교안) vs `P i + Q j + R k`(Stewart) — 같은 문자 P가 정반대 성분. 면적소 `dσ`(교안 122회) vs `dS`. `∇×F, ∇·F` vs `curl F, div F`. 발산정리 영역 `D` vs `E`. 구면좌표 순서 `(ρ,φ,θ)` vs `(ρ,θ,φ)`(φ 의미는 동일).
5. **공통과제 제출 124문항 중 약 22문항은 같은 유형 카드가 아예 없다**(§5). 나머지는 완전 또는 부분 대응.
6. **Thomas 고유 내용은 생각보다 적다.** 선형근사·이차근사의 오차 상계(½M(Σ|Δ|)², ⅙M(Σ|Δ|)³), 3차 테일러, 종속변수 제약 `(∂w/∂x)_{y,z}`, 감마함수, 음함수 곡면 넓이 공식 `|∇F|/|∇F·p|`, 2차원 flux·순환밀도·발산밀도·완전형식, 극좌표 운동 `u_r, u_θ`, 임용 기출 40여 문항. 반면 추세선·혈액형·Cauchy-Schwarz·4차원 구 부피·열률·a_T/a_N 등은 Stewart에도 있다(연습문제·Discovery Project 포함).

## 4. 표기·용어 충돌표 (교안 → Stewart)

| 항목 | 교안(calc2 실측) | Stewart 9e | 심각도 |
|---|---|---|---|
| 벡터장 성분 | `F = M i + N j + P k` (ch12 12회) | `F = P i + Q j + R k` | **높음** — P가 정반대 성분 |
| 그린 정리 | `∮F·T ds = ∬_R (N_x − M_y) dx dy` (ch12 ex05) | `∮ P dx + Q dy = ∬_D (Q_x − P_y) dA` | 높음 |
| 면적소 | `dσ` (ch13 74회, ch14 48회; dS는 임용 pr03 4회뿐) | `dS`, 벡터 면적소 `dS` | **높음** |
| 플럭스 | `∬_S F·n dσ`, 용어 "유출" | `∬_S F·dS`, flux | 높음 |
| 회전·발산 | `∇×F`, `∇·F` 주 표기 | `curl F`, `div F` (∇ 표기는 보조) | 중 |
| 적분 영역 문자 | 평면 `R`, 입체 `D` (ch10 ∭_D 58회) | 15.1 직사각형 `R`, 일반 평면영역 `D`, 입체 `E` (Stewart의 D = E의 정사영) | 높음 |
| 구면좌표 | `(ρ, φ, θ)`, `dV = ρ² sinφ dρ dφ dθ` (10회) | `(ρ, θ, φ)`, `dV = ρ² sinφ dρ dθ dφ` (p.1178 WARNING: 표기 합의 없음) | 중 — φ 의미(z축에서 잰 각)와 값은 동일, 순서만 반대. 과제 15.8 #18이 Stewart 순서로 출제 |
| 원기둥좌표 용어 | "원통좌표계" | cylindrical coordinates(국내 "원기둥좌표"도 통용) | 낮음 |
| 영역 유형 | 용어 없음 | Type I/II(평면), type 1/2/3(입체) | 중 |
| 야코비안 | `∂(x,y)/∂(u,v)` | 동일 (`J(u,v)`는 양쪽 0회) | 없음 |
| 벡터 성분 | 소괄호 `(a,b,c)` + `i,j,k` | 꺾쇠 `⟨a,b,c⟩` | 낮음 |
| 스칼라 정사영 | 기호 없이 "스칼라 성분" | `comp_a b` | 낮음 |
| 직선·법선 | 매개변수식만 | 대칭방정식 `(x−x₀)/a = …` 병용 | 낮음 |
| 이차곡면 | 쌍곡포물면 `y²/b² − x²/a² = z/c`; "elliptical paraboloid/cone" | `z/c = x²/a² − y²/b²`(안장 방향 90° 다름); "elliptic paraboloid", "cone" | 중 |
| 혼합 편도함수 | Leibniz `∂²f/∂x∂y(0,0)=1`, `∂²f/∂y∂x(0,0)=−1` (U06 yu02-3) | 첨자 `f_xy(0,0)=−1`, `f_yx(0,0)=1` (14.3 #101, 동일 함수) | 없음 — 표기만 다르고 값 일치(`f_xy = ∂²f/∂y∂x`) |
| 첨자 번호 표기 | 없음 | `f₁, f₂, D₁f, f₁₂` 병기 | 낮음 |
| 음함수 미분 | 매번 양변 미분 | 공식 `∂z/∂x = −F_x/F_z` (식 6) — 과제 14.5 #38이 공식 사용 명시 | 중 |
| 방향도함수 | `D_u f(x₀,y₀)` — 이미 Stewart식 | 동일 | 없음 |
| 접평면 | 항상 등위면형 `∇F·(x−x₀)=0` | `z−z₀ = f_x(x−x₀)+f_y(y−y₀)` 먼저, 등위면형은 14.6 | 낮음 |
| 라그랑주 문자 | U08 ex02(1) 목적 g·제약 h | 목적 f·제약 g=k | 낮음(1건) |
| 평균값 | `Avg(f)` | `f_avg` | 낮음 |
| 보존장·퍼텐셜 | "보존적벡터장", "잠재함수" | conservative, potential function(국내 통용 "퍼텐셜 함수") | 낮음 |
| 향 반전 | 서술만 | `−C` 표기 | 낮음 |

## 6. 반영 권고 (우선순위)

**P0 — 표기 정합(카드 신설 없이 가능)**
- U11–U14 카드 상단 배너: "Stewart는 `F = P i + Q j + R k`, 본 교안은 `M i + N j + P k`(P의 의미가 다름)". 그린 정리는 `∬(Q_x − P_y) dA` 병기.
- U13·U14 `dσ` → `dS`(122곳), `∬F·n dσ` → `∬F·dS` 병기, `∇×F`/`∇·F`에 `curl F`/`div F` 병기, 발산정리 영역 D → E.
- U10 구면좌표 카드마다 한 줄 주석: "Stewart 순서 (ρ,θ,φ)·dρ dθ dφ, φ 의미 동일".
- U09·U10에 Type I/II, type 1/2/3 용어 도입(기존 카드 재분류).

**P1 — 과제 직결 공백 카드(약 20장)**
- 응용 3종: 이중적분(15.4 전체), 삼중적분(15.6 식 13–16), 선적분·면적분 질량중심(16.2 식 4, 16.7).
